<h1 align="center"> Global Freelancers Data Cleaning and Analysis</h1>

<p align="center">
  A Python project focused on cleaning, preprocessing, analyzing, and visualizing a global freelancers dataset.
</p>

<hr>

<h2>📌 Project Overview</h2>

<p>
This project focuses on <strong>data cleaning, preprocessing, analysis, and visualization</strong>
using a dataset of <strong>1,000 global freelancers</strong>.
The dataset contains incomplete and inconsistent data, including missing values,
special characters, incorrect data types, invalid ages, and inconsistent categorical values.
</p>

<p>
The main goal is to transform the raw dataset into a cleaner and more reliable dataset
and then perform statistical analysis and visualization to understand the data.
</p>

<h2>🎯 Project Objectives</h2>

<ul>
  <li>Clean and preprocess the raw freelancer dataset.</li>
  <li>Handle missing values.</li>
  <li>Remove unnecessary special characters from numerical data.</li>
  <li>Convert columns into appropriate data types.</li>
  <li>Identify and handle invalid age values.</li>
  <li>Standardize inconsistent gender values.</li>
  <li>Perform statistical analysis on the cleaned dataset.</li>
  <li>Explore relationships between different variables.</li>
  <li>Create visualizations to understand the data.</li>
</ul>

<h2>📊 Dataset</h2>

<p>
The dataset contains <strong>1,000 freelancer records</strong> with information including:
</p>

<ul>
  <li>Freelancer ID</li>
  <li>Name</li>
  <li>Gender</li>
  <li>Age</li>
  <li>Country</li>
  <li>Language</li>
  <li>Primary Skill</li>
  <li>Years of Experience</li>
  <li>Hourly Rate (USD)</li>
  <li>Rating</li>
  <li>Active Status</li>
  <li>Client Satisfaction</li>
</ul>

<h2>🧹 Data Cleaning</h2>

<p>
Several data cleaning and preprocessing techniques were applied, including:
</p>

<ul>
  <li>Handling missing values.</li>
  <li>Removing special characters such as <code>$</code> and <code>%</code>.</li>
  <li>Converting numerical columns to appropriate data types.</li>
  <li>Validating age values.</li>
  <li>Standardizing gender categories such as <code>M</code>, <code>m</code>, <code>MALE</code>, <code>F</code>, and <code>female</code>.</li>
</ul>

<h2>📈 Data Analysis</h2>

<p>
After cleaning the dataset, several statistical analyses were performed, including:
</p>

<ul>
  <li>Variance and standard deviation of age.</li>
  <li>Median hourly rate.</li>
  <li>Median client satisfaction.</li>
  <li>Correlation between age and years of experience.</li>
  <li>Average years of experience by country.</li>
  <li>Top 10 most common freelancer skills.</li>
</ul>

<h2>📉 Data Visualization</h2>
